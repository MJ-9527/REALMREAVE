# 商店材料补给 · 一键补齐 · 出口显眼化 · 怪物难度下调

## Summary

本次改动三件事，全部落在 `prototype/` 原型内：

1. **商店新增「材料补给」货架**：按轮次开放白 / 蓝 / 紫三种品质的基础材料（铁锭、皮革、硬木、兽筋）无限量购买，让合成不再被辅材卡死；魔晶、秘银仍只能在节点搜刮，作为核心材料。
2. **合成栏新增「一键补齐」**：缺料的配方显示 `补齐并合成 N`，点击后按商店价买齐缺失的基础材料并立即合成；物资点不足时整笔不执行，日志提示差额。
3. **出口更显眼 + 怪物变弱**：出口节点放大、加双层光环与底部「出口」文字，地图图例增加出口条目；怪物编成改为第 1 轮 2 普通 / 第 2 轮 3 普通 / 第 3 轮 4 精英，等级降为 `max(1, round-1)`。

### 1. `prototype/js/data.js`

在 `SHOP_QUALITY` 之后追加两张常量表，并把文件头版本注释升到 v0.7：

/* ---------------- 商店材料补给 ---------------- */

// 每次轮间补给开放的基础材料品质（魔晶 / 秘银不售卖）
const MAT_SUPPLY = {
  1: ['white', 'blue'],
  2: ['white', 'blue', 'purple'],
  3: ['white', 'blue', 'purple']
};

// 只有这些材料可以从商店买到，魔晶 / 秘银 必须搜刮

**为什么这么定价**：回收价白 1 / 蓝 1 / 紫 2，售价 2 / 4 / 6 全部高于回收价，商人 −30% 后为 1 / 3 / 4，仍然不产生套利（白 1 买 1 卖为持平，但白色材料本身不构成本收益）。

#### 2.3 「一键补齐」报价与执行

```js
/** 配方缺料清单 + 补齐报价；不可补齐时 ok=false */
function fillQuote(p, r) {
  const need = {};
  need[r.main] = 1;
  for (const a of r.aux) need[a] = (need[a] || 0) + 1;

  const miss = [];
  for (const name in need) {
    const lack = need[name] - matCount(p, name);
    if (lack > 0) miss.push({ name, lack });
  }
  if (!miss.length) return null;

  const qu = matSupplyTop(G.round);
  for (const m of miss) {
    if (!BASE_MATERIALS.includes(m.name)) return { ok: false, miss, blocked: m.name };
  }
  const unit = priceFor(p, MAT_PRICE[qu]);
  const total = miss.reduce((s, m) => s + m.lack * unit, 0);
  return { ok: true, miss, qu, unit, total };
}

function craftWithFill(id) {
  const me = G.me;
  const r = RECIPES.find(x => x.id === id);
  if (!me || !r) return;
  if (craftCheck(me, r)) { doCraft(id); return; }

  const q = fillQuote(me, r);
  if (!q || !q.ok) {
    log(`该配方缺少核心材料（${q ? q.blocked : '—'}），只能靠搜刮`, '');
    renderShop();
    return;
  }
  if (budgetOf(me) < q.total) {
    log(`物资点不足：补齐需 ${q.total}，当前 ${budgetOf(me)}，差 ${q.total - budgetOf(me)}`, '');
    renderShop();
    return;
  }
  payFrom(me, q.total);
  for (const m of q.miss) {
    for (let i = 0; i < m.lack; i++) me.materials.push({ n: m.name, q: q.qu });
  }
  const chk = craftCheck(me, r);
  if (!chk) { renderShop(); return; }
  const res = craftInto(me, r, chk);
  log(`补齐并合成 <span class="q-${res.eq.quality}">${res.eq.name}</span>（-${q.total} 物资点）`, 'hl');
  renderShop();
  renderSide();
}
```

**决策：补齐材料统一按「当前轮开放的最高品质」购买。** 理由：辅材品质不影响成品品质（成品品质只看主材），主材缺失时也只能用商店能给的最高品质，统一口径最简单、无歧义；第 1 轮买蓝、第 2/3 轮买紫。

**成本示例**：第 1 轮缺 2 件辅材 → `2 × 4 = 8` 物资点；第 2 轮起缺 2 件紫辅材 → `2 × 6 = 12`。

## Assumptions & Decisions

| 项 | 决策 | 依据 |
|---|---|---|
| 材料补给开放节奏 | 第 1 轮 白/蓝；第 2 轮起 白/蓝/紫 | 用户选择「白/蓝 → 加紫 → 全开」 |
| 可购买材料范围 | 仅铁锭 / 皮革 / 硬木 / 兽筋 | 用户表述「让合成基本只需要核心材料」，魔晶 / 秘银 作为核心材料保持稀缺 |
| 材料售价 | 白 2 / 蓝 4 / 紫 6，商人 −30% | 必须高于 70% 回收价（白 1 / 蓝 1 / 紫 2）以防套利 |
| 供应量 | 无限量，逐件点击买入 | 不做数量选择器，避免过度设计 |
| 一键补齐行为 | 买齐缺失材料后**立即合成** | 用户选择「买齐并直接合成」 |
| 补齐材料品质 | 当轮开放的最高品质 | 辅材品质不影响成品品质；主材缺失时也只能取商店能给的上限 |
| 补齐资金不足 | 整笔不执行，日志提示「需 X，当前 Y，差 Z」 | 用户选择「整笔不执行并提示差多少」 |
| 不可补齐的配方 | 缺魔晶 / 秘银 时保持「缺料」禁用 | 核心材料必须搜刮 |
| 怪物削弱方式 | 数量与等级同时降 | 用户选择「数量与等级同时降」 |
| 出口动效驱动 | 120ms `setInterval` + `renderMapOnly()`，仅 `explore` 阶段生效 | 现有 `render()` 无持续循环，且不能整页重建 DOM |
| 命中判定 | 不改 `mapHitNode` 的 28px | 基于中心距离，节点放大不影响 |
